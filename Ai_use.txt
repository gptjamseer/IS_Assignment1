기존에 기록한 Task 1 요청 원문

Implement Task 1 in Task1.py using Python and PyGAD.

Read the actual data from:

- Classes.txt
- Classrooms.txt
- Teachers.txt

Represent each lecture using three genes:

[start_time, classroom_index, teacher_index]

The fitness function must penalize:

1. Teachers assigned to subjects they cannot teach.
2. Lectures outside classroom availability.
3. Overlapping lectures in the same classroom.
4. Teachers assigned to overlapping lectures.

Use PyGAD’s default population, selection, crossover, and mutation operations.
Do not implement Task 2 features such as custom populations, crossover, or
mutation.

After execution:

- Print the best fitness.
- Print all constraint violation counts.
- Print the final schedule with start time, end time, classroom, subject, and
  teacher.
- Save a graph of the best fitness per generation as task1_fitness.png.

Keep the code simple, readable, and approximately 150–250 lines. Use basic
lists, dictionaries, and small functions. Do not add unnecessary classes,
command-line options, or complex error handling.

Run and verify the program using the provided input files before finishing.
